publish-pr-html のサンプル解説

このファイルは CLI の動作確認用です。CSS はインラインで、外部リソースを参照しません。

この HTML が検証していること

項目内容
日本語「こんにちは」「解説」などの多バイト文字を含む
引用符"double" と 'single' の両方を含む
シェル構文$(rm -rf /)、`whoami`、${HOME} をそのまま含む
バックスラッシュC:\path\to\file と \n

転送の流れ

CLI: SHA-256 を計算 → PR の head を確認 → 転送方式を判定 → dispatch
workflow: 入力検証 → HTML 取得と検証 → 非 ZIP artifact → PR コメント更新

確認ポイント

  1. PR コメントのリンクから、この HTML がブラウザでそのまま表示されること。
  2. コメントに記載された対象コミットが、CLI に渡した SHA と一致すること。
  3. 同じ内容を再送しても、コメントが重複しないこと。
